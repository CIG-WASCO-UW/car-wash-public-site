Using the repository

How to use these case studies

Use each case to understand a specific adaptation action, then check the original source, implementation context, and reported evidence before applying the lesson elsewhere.

1. Find a relevant action

Filter by hazard, geography, sector, strategy, and implementation stage. Each record focuses on a specific action or program.

2. Check the evidence

Open the original source and distinguish completed work from plans, reported benefits, and measured outcomes.

3. Consider local fit

Review governance, scale, climate mechanism, implementation stage, and site constraints before transferring a lesson.

4. Cite and improve

Use the citation and original-source link. Report broken links, inaccurate fields, or accessibility problems to the project team.

Methodology and definitions

Cases are screened for adaptation relevance, bounded action, usable source evidence, and review needs. Inclusion in this staging library does not by itself establish effectiveness or publication approval.

Planned / pilot
Action is proposed, funded, designed, or being tested. Benefits must not be described as measured outcomes.
Implemented / operational
Action exists or is operating. Outcome claims still require explicit source evidence.
Transferability
Conditions under which an approach may inform another place; it is not a guarantee of equivalent results.
Update cycle
Source status and case fields are checked through a human-reviewed workflow before a new public version is released.
