# CAR-WASH Public Beta Repository

This repository contains the public-facing, human-reviewed static snapshot for
the CIG/WASCO CAR-WASH case-study repository.

- Source application: `CIG-WASCO-UW/car-wash-platform`
- Team review registry: `CIG-WASCO-UW/car-wash-team-registry`
- Publication boundary: only approved public snapshots belong here
- Original CAR-WASH Airtable: read-only and never a write target

The site is a beta research resource. It is not an automated publication system,
and model output does not replace human review.
